# 与原版的差异（实测对比）

上游: https://github.com/ZSeven-W/dsh-android (rc.8, commit 209c0f6)
本 fork: 在其之上 20 个 commit

所有数字均为**实机实测**（小米平板5 / M2105K81AC / Android 13 / MIUI 14），
设备型号与测量方法在各节标注。未实测的一律标注为推算。

## 一、延迟

### `android_ui_tree` 端到端（**上游源码直接编译对照**，各 5 次取 p50）

方法：把上游 `origin/main`（209c0f6）单独 checkout 并编译，与 fork **各自独立进程**
测量（两个 host 在同一进程内会争用 adb 连接，实测会产生 60s 级伪影）。

| 屏幕 | 上游 rc.8 | 本 fork | 加速 |
|---|---:|---:|---:|
| WLAN | 2203 ms | **3 ms** | **734x** |
| 设置 | 2195 ms | **2 ms** | **1098x** |
| 应用 | 2209 ms | **4 ms** | **552x** |

更长采样（同一屏，各 8 次，隔离进程）：

    上游 : 2204, 2212, 2187, 2202, 2215, 2178, 2205, 2194  -> p50 2204 ms

**约 730 倍**，且两边的方差都很小（上游 sd ~15ms，fork sd ~1ms）。

## 二、Token

同一屏（设置页，fixture 23121 字节）：

| 路径 | 载荷 | 完整度 |
|---|---:|---|
| `android_ui_tree` 全量（原版与本 fork 相同）| 13,111 B | 截断 |
| `android_ui_tree` actionable（本 fork）| **7,125 B** | 完整 |

实测多屏节省（settings / wifi / apps / display）：**56–59%**。

另实测（真机）：

| 路径 | ≈tokens |
|---|---:|
| `android_ui_rows` | ~1,050 |
| 截图（图片路径）| ~1,970–2,635 |
| `android_ui_tree` | ~10,300 |

**重要发现**：图片比全量树**便宜 3–5 倍**（此前普遍假设相反）。

## 三、修复的真实缺陷

### 1. tap 纵向漂移（**原版存在**）

原版代码：

```ts
// tool-uitree.ts（原版第 784 行）
const tap = { x: center.x / screen.width, y: center.y / screen.height }  // 分母 = 树高度 ~1500

// android-host.ts（原版第 533 行）
#pixels() { y: Math.round(y * frame.height) }                              // 乘数 = 实时帧 ~1536
```

两者**假定同一个分母，实际差 36px**（app 帧 vs 完整显示区）→ 每次 tap 偏上/偏下
最多 **35 px**；靠近屏幕底部的控件**根本点不中**（落到手势条被吞）。

本 fork 修复后实测漂移 **0 px**，并已在真机上验证「点安装按钮真的装上了」。

### 2. 图像链路静默失效（原版存在）

`resolveVisionServices` 在 `apply()` 时急切采样并缓存，而 `ctx.get()` 默认 strict，
服务未激活时返回 `{}` 并被**永久冻结**；且守卫只检查 `saveImage` 而漏了 `saveImages`。
后果：截图工具**从未真正把图交给模型**，且完全静默。

### 3. 静默截断（原版存在）

原版超出 40 KB 时**整层删除最深节点**（最具体的控件），返回一棵**看起来完整**的树。
本 fork 改为按兄弟节点稀释（优先保留可操作节点）并**明确报告丢了什么**。

## 四、新增能力

| 能力 | 说明 | 需要额外安装？ |
|---|---|---|
| `android_query` / `android_assert` | 语义读屏，截图交给调用方模型 | 否 |
| `if_moved` 缓存 | 屏幕未变则不重复 dump | 否 |
| 常驻桥接（bridge）| dump 从 2.4s 降到 4ms | **是**（需装 APK + 授权）|
| `view: "actionable"` | 省 56–59% token | 否 |
| revision 缓存 | 空闲屏 2–4 ms | 需 bridge |

**桥接是纯加法**：未安装 / 未授权 / 超时 / 任何异常一律静默回退到 uiautomator。
已实测四种回退场景（无桥 / 返回 undefined / 抛异常 / 正常），行为与不回退时一致。

## 五、兼容性

| 项 | 状态 |
|---|---|
| `view` 省略时 | **逐字节等同于 `full`**（有 5 条契约测试锁定）|
| 工具名与参数 | 未增删（只新增可选 `view`）|
| 结果结构 | 未变 |

已用 23121 字节真实 fixture 验证：**两版本的 `full` 输出逐字节相同**。
